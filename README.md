# Palette-Editor
Web App to edit 8-bit palettes. Made with Claude.

Allows you to open indexed PNGs and mouse over and select from the image, the color you wish to edit.


Instructions
---------------------
1. Save an indexed PNG of the palette you wish to work with.
2. If you're sampling colors from another image have that ready as well.
3. Click open PNG to open the indexed image you wish to work with.
4. Click load reference, if you're using one.
5. Click the color on your character in the left panel you wish to edit. Here you can edit RGB values manually, with a color selector, or with a hex value. If you want to sample a color from your reference, right click on said color on the reference image.
6. When you're finished you can save your results as either a PNG you can import directly into Fighter Factory, but if you wish to save as an ACT file, be sure to check "reverse order" before doing so.


Tips
----------
CTRL+Z or CMD+Z undos your last change
Holding spacebar undarkens unselected areas, so you can see your results more clearly.
